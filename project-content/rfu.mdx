## About the project

I created RFU to help people find useful opportunities and learning resources in one place. I built and launched the first version, and I continue to update the website and manage the Facebook page.

## What you can find

- Hackathons and events
- Webinars and courses
- Other useful resources for learning

## Why I built RFU


    I wanted to make learning resources and opportunities easier to find in one place. Some beginners had sent me messages asking where they could find opportunities like hackathons and webinars.
