## Why I built VBot

ကျောင်းတက်တုန်းက website တွေကို ခပ်မိုက်မိုက် UI တွေနဲ့ လုပ်ချင်ခဲ့တယ်။ Background video တွေ လိုက်ရှာရင်း Pinterest မှာ သဘောကျတဲ့ video တွေ တွေ့ပေမယ့် download လုပ်ဖို့ မလွယ်ခဲ့ဘူး။ Screen recording လုပ်ကြည့်တော့လည်း ပုံရိပ်က မှုန်ဝါးနေတယ်။

TikTok မှာ ကိုယ်ကြိုက်တဲ့ post တွေကို story မှာ ပြန်တင်ချင်တဲ့အခါ username watermark ပါနေတာကို မကြိုက်ဘူး။ Instagram နဲ့ X က video တွေကို သိမ်းချင်တဲ့အခါမှာလည်း platform တစ်ခုချင်းစီအတွက် download လုပ်နည်းတွေ လိုက်ရှာရတယ်။

YouTube music video တွေ download လုပ်ဖို့ website တချို့ကို သုံးကြည့်တဲ့အခါလည်း banner တွေ၊ pop-up တွေကြောင့် စိတ်ရှုပ်ရသလို လုံခြုံတယ်လို့လည်း မခံစားရဘူး။

## What VBot does

ကိုယ့် personal use အတွက် ဒီအခက်အခဲတွေကို ဖြေရှင်းချင်လို့ ရှာကြည့်တဲ့အခါ အဆင်သင့် ရေးထားတဲ့ GitHub codebase တစ်ခုကို တွေ့ခဲ့တယ်။ ဒါပေမယ့် အဲဒါကို သုံးဖို့ terminal ကနေ command တွေနဲ့ download လုပ်ရတယ်။

Tech သမားတွေတင်မကဘဲ သာမန် user တွေလည်း အလားတူ အခက်အခဲတွေ ရှိနေနိုင်တာမို့ link ကို paste လုပ်ရုံနဲ့ ပိုပြီး လွယ်လွယ်ကူကူ သုံးနိုင်အောင် Telegram bot လေး လုပ်ဖြစ်ခဲ့တာပါ။ Python ကို self-study လုပ်ရင်း လက်တွေ့လေ့ကျင့်ချင်တဲ့ ရည်ရွယ်ချက်လည်း ပါပါတယ်။
