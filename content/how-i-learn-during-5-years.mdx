AI တွေပေါ်လာတာ ကောင်းလည်းကောင်းတယ်၊ မကောင်းလည်း မကောင်းဘူး။ အရင်က ၂၀၂၄ လောက်အထိ AI တွေ သိပ်မတွင်ကျယ်သေး (ကိုယ်က beginner ဆိုတော့ မသုံးတတ်သေးတာရယ် လက်လှမ်းမမှီတာရယ်၊ သုံးရတာလည်း ကိုယ်ရေးတယ်လို့မခံစားရလို့ မသုံးဘူး) ခင်က Google နဲ့ Stack Overflow ကနေပဲ မသိတာ ရှာမေး၊ ရေးရတာ။ 

အဲ့တုန်းက ဒါပြီးရင် ဘာဆက်လုပ်ရမလဲ ဘယ်သူ့ကိုမှလည်း မေးရမှန်းလည်း မသိခဲ့ဘူး။ မိသားစုထဲလည်း ကိုယ်က ပထမဆုံးဆိုတော့ အသိလည်းမရှိ၊ စီနီယာရော ဂျူနီယာရော မရှိ။ ကျောင်းလည်း မတက်။ Online ကနေ သင်တန်းတက်တော့ သူငယ်ချင်းလည်း မရှိ။ စာလည်းမရိုက်ရဲ စကားလည်းမပြောရဲနဲ့။

## ကိုယ့်ဘာသာ စလေ့လာခဲ့တဲ့အချိန်

အဲ့လိုပဲ အခန်းထဲ နေ့မနားညမနား Facebook Page UI clone , Instagram UI Clone ကနေစပြီး တိုလီမုတ်စတွေ အကုန်ရေး။ js နဲ့ နာရီလက်တံလေးရွေ့အောင် လုပ်နိုင်တာကိုပဲ အရမ်းပျော်။

နောက် HTML, CSS, JS အပြင် Bootstrap လေး သင်ပြီးသွားတော့ project ဆိုပြီး ရေးခဲ့တဲ့ ရေမွှေး landing page လေးကနေစပြီး ဖြေးဖြေးချင်း ကိုယ့်ကိုယ်ကိုယ် ယုံကြည်မှုတွေ တက်လာတယ်။

နောက် PHP သင်ပြီးတော့ full-stack project လေးအဖြစ် e-commerce လေး ရေးတယ်။ Tutorial video တွေကြည့်ပြီး ရေးတတ်တဲ့သူလည်း မဟုတ် ( Video ကြည့်ရင် ကိုယ် error ဖြစ်တဲ့နေရာ ရှာရ အရမ်းကြာလို့ )။ 
သူများရေးပြီးသားဟာ လိုက်ကူးတာမျိုး မလုပ်ချင်လို့ဆိုပြီး ကိုယ့်ဘာသာ အဲ့လိုပဲ ရေးတာ။  

## အမှတ်တရ ပြဿနာတစ်ခု

rating and review ပေးတဲ့ feature မှာ nested comments/reply လို့ခေါ်မလား အဲ့ဟာမှာ ၂ ပတ်လောက် နေ့မအိပ်၊ ညမအိပ် တိုင်ပတ်ခဲ့တာ။ မနက် ၄ နာရီမှ ဖြေရှင်းနိုင်လို့ ဧည့်ခန်းထဲမှာ အရူးကြီးလို တစ်ယောက်တည်း ခုန်ပေါက်ကပြီး ပျော်လွန်းလို့ ငိုခဲ့ရသေးတယ်။

အဲ့ဟာအပြင် Laravel လေးကလည်း သင်နေတော့ Laravel project တွေလည်း ရေးပေါ့။

Online အတန်းတက်တဲ့ ၃ နှစ်မှာ နားခဲ့တယ်ဆိုတာ မရှိသလောက်ပဲ။ အိပ်ရာနိုးတယ်၊ ထပြီး ကွန်ပျူတာအရှေ့ထိုင်တယ်။ ၂၀၂၁ - ၂၀၂၄ အထိ အချိန်တွေကို ပြန်တွေးကြည့်ရင် laptop ရှေ့က လူလို့ပဲ မြင်ရတယ်။ တစ်နေ့တစ်နေ့ မလုပ်ဘူးဆိုရင်တော့ ၁၀ နာရီလောက် အသားတင် (ထမင်းစား၊ ဘာညာကိစ္စတွေ မပါ) လေ့ကျင့်နေတာဆိုတော့။

အမှန်ဆို အဲ့ချိန်လောက်ကတည်းက intern လေးပဲဖြစ်ဖြစ် ၀င်လုပ်လိုက်မယ်ဆိုရင် လုပ်ငန်းခွင်ထဲ အတွေ့အကြုံကနေ သင်သွားမှာကို မသိခဲ့ဘူး။ 

## AI နဲ့ သင်ယူရင်း သတိထားမိခဲ့တာ

အဲ့လိုနဲ့ ၂၀၂၄ နှစ်ကုန်ကစပြီး ၂ နှစ်လောက် ကျောင်းတက်လိုက်တဲ့အတောအတွင်း AI က မြန်မြန်ကြီး  develop ဖြစ်လာတော့ အဲ့နောက်ကို လိုက်ရင်းနဲ့ error ဖြေရှင်းနိုင်လို့ရတဲ့ ခံစားချက်တွေလည်း သိပ်မရှိတော့သလို၊ တကယ်တမ်း ကိုယ့်ဘာသာ ပြန်ရေးရမယ်လည်းဆိုရင် ဘယ်ဟာမှ သေချာမမှတ်မိတော့ဘူး။

အဲ့တော့မှ dependency အရမ်းဖြစ်နေတယ်ဆိုတာ ကိုယ့်ကိုယ်ကိုယ် သတိပြုမိတော့တယ်။

၅ နှစ်အတောအတွင်း laptop သုံးလုံးလောက် လဲလိုက်ရလို့ Database တွေ ပျက်တာရယ် git ပေါ် တစ်၀င်ပျက်ရောက်တာလေးတွေရယ်။ ဒါလေးတောင် video ရိုက်ထားမိလို့တော်သေး။ ခုန်ပေါက်ခဲ့ရတဲ့ည ဆိုတော့။
