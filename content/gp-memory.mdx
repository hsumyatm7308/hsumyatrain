#### “ဆုမြတ်မိုးရေ OTP”
#
၂ နှစ်တာကာလရဲ့ အရာအားလုံးကို ချုပ်ငြိမ်းပေးခဲ့တဲ့ စကားစုလေးပါပဲ။ အခုချိန်ထိလည်း ကြားယောင်တိုင်း ကြောက်ရွံ့နေဆဲပါ - စတာပါ၊ နောက်တာပါ... အတည်ပါ။

လွန်ခဲ့တဲ့ ၆ လ၊ ၇ လ လောက်ကို သွားကြည့်လိုက်ရင် အပတ်စဉ် သောကြာနေ့ည 8 နာရီတိုင်း meeting ခေါ်တယ်။ Business လား logic လား စသည်ဖြင့် အဘက်ဘက်ကနေ စဉ်းစားပြီး ဆွေးနွေးငြင်းခုန်ကြတာပဲ။ project က wedding အကြောင်းဆိုတော့ အာပလာလေးတွေလည်း ရွှီးရင်းပေါ့။  

ဒီလိုနဲ့ လတွေကြာတဲ့အခါ meeting က အပတ်တိုင်းဆိုတော့ ကျုပ်တို့ leader တွေမှာ အဆဲခံရတာလေးတွေလည်း ရှိတာပေါ့။ အဲ့ထဲမှာ  အဆဲခံရဆုံးက ကျွနုပ် ဆုမြတ်မိုးပေါ့နော်။ Deadline တွေပေးပြီး မနားခိုင်းလို့ပါ။ အဆဲဆုံးကတော့ မယု နဲ့ ဓန ဖြစ်ပြီး ခေါ်မကြား အော်မကြားကတော့ မဆုဝဒီမြတ်နိုး ပေါ့နော်။ 

Final Project Deadline မရောက်ခင် သုံးပတ်အလိုမှာ ကိုယ်က One Project One Week Hackathon ပြိုင်ရတယ်။  

အရှေ့မှာ အချိန်ယူပြီး လပေါင်းများစွာ ဆွေးနွေးခဲ့ပေမယ့် ကိုယ် ပြိုင်ပွဲမသွားခင် ညရဲ့ meeting မှာ management သမား ကလည်း နေမကောင်းတော့ မလာဖြစ်တာကနေ ဆက်သွယ်မှု လွဲချော်သွားတာကြောင့် ကိုယ်ပြန်ရောက်လာတဲ့အချိန်မှာ implementation စမလုပ်ရသေးဘူး။  

အခြားသော Team တွေက ပြီးလုနီးနေပြီ။ တစ်ချို့ဆို Testing တွေ စမ်းနေကြပြီ။ အခြေအနေတွေ လိုက်မေးကြည့်တော့ 80%, 70%, 50%, 40% တွေ ပြီးနေကြပြီ။ ကိုယ်တွေမှာတော့ 20% တောင် မပြီးသေးဘူး။ Deadline က နောက် ၂ ပတ်နေရင်။

ကျန်တဲ့ စစ်သူကြီး လေးယောက်ကလည်း အဲ့ချိန်မှာ ဂျပန်စာ N2 ဖြေဖို့နဲ့ Interview အတန်းအတွက် ရုန်းကန်နေရချိန်ပဲ။ 

အဲ့ချိန်မှာ team သားအားလုံးကို code ရေးစေချင်တဲ့ ကိုယ့်အတွက် ခက်ခဲတဲ့ဆုံးဖြတ်ချက် ချခဲ့ရတယ်။ Project implementation တစ်ခုလုံးကို တစ်ယောက်တည်းပဲ ကိုင်ဖို့ ဆုံးဖြတ်လိုက်ရတယ်။ Team work စွမ်းအားကို နားမလည်သေးတာကြောင့် ကိုယ့်တစ်ယောက်တည်းလို့ တွေးခဲ့မိပြီး ကိုယ်ဦးဆောင်တဲ့ project ကရော ဘယ်လိုအဆုံးသတ်မလဲ ဆိုတာမျိုး တွေးကြောက်ခဲ့တယ်။ 

ကျောင်းမတက်ဘဲ အိမ်မှာပဲ ရှူးပေါက်ချိန်နဲ့ ရေချိုးချိန်ကလွဲလို့ တစ်ပတ်လုံး နေ့မအိပ်၊ ညမအိပ်ဘဲ ရေးပြီးတဲ့နောက် အားကိုးရတဲ့စစ်သူကြီး ၄ ယောက်လည်း ပြန်ရောက်လာခဲ့ပါတယ်။

Data Analysis ပိုင်းကို ဦးဆောင်တဲ့ ဓန၊  Documentation ကို ဉီးဆောင်တဲ့ မယု၊ ကောင်းမင်းခန့်၊ ကိုယ့်ရဲ့ အကောင်းစား UI/UX ကို ပြင်ပေးရတဲ့ Designer ဝင်းလဲ့ရွှေရည် (management နဲ့ ဘက်စုံ), PPT မှာ ဂျွတ်ထနေတဲ့ Artist ဆုဝဒီမြတ်နိုး နဲ့  usecase ပိုင်းတွေမှာ စိတ်ချထားရတဲ့ နော်ပန်းရတနာထွန်း, image resolution တွေ နဲ့ data searching စတဲ့ အရာတွေမှာ အားကိုးရတဲ့ အိအိဖြူ၊ လဲ့ရတီထွန်း၊ ဇော်မင်းသိန်း စတဲ့ အဖွဲ့သားတွေက သက်ဆိုင်ရာ role တွေမှာ စိတ်ချရအောင် အတူတူ ပူးပေါင်းလုပ်ဆောင်ပေးခဲ့ကြတယ်။ ဒီအချိန်မှာပဲ teamwork ဆိုတာ ဒါပါလားဆိုတာကို အပြည့်အဝ ခံစားလိုက်ရတယ်။ 

Project ပြရမယ့်နေ့မတိုင်ခင်မှာ မယုက business logic ယိုပေါက်တစ်ခု တွေ့ခဲ့တယ်။ Data တွေလည်း မထည့်ရသေးတာကြောင့် ည ၂ နာရီအထိ အလုပ်ရှုပ်ခဲ့ကြရပြန်ပါတယ်။ 

System က အားလုံးအလုပ်လုပ်ပြီးချိန်မှ Data တွေ ထည့်တာကြောင့် Admin role ဖြစ်တဲ့ ကျုပ်ရဲ့ email နဲ့ ချိတ်ထားတာကြောင့်  OTP က ကိုယ့်ထဲပဲဝင်နေတော့ တစ်လျှောက်လုံး အတောင်းခံခဲ့သမျှ ထိုညမှာ ပိုပြီးမနားတမ်း အတောင်းခံရတာ Project ပြီးဆုံးတဲ့အထိကို ဖြစ်ပါတယ်။

ဒီအဖြစ်အပျက်လေးတွေကို အမှတ်တရ ပြန်တွေးမိရင်း နောင်တကင်းကင်းနဲ့ ပျော်ရွှင်ခဲ့ရတဲ့ ကျောင်းတက်ချိန်တွေကို ပြန်လွမ်းမိပါတယ်။
