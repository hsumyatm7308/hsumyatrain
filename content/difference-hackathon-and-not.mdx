ကိုယ့်ဘာသာ project တွေ ရေးပြီး လေ့ကျင့်နေတဲ့သူနဲ့ hackathon ပွဲတွေ ဝင်ပြိုင်ဖူးတဲ့သူ ဘာကွာလဲ။

စာရေးသူအတွက်တော့ အဓိကက **mindset ကွာသွားတာပါပဲ။** ကိုယ်တိုင် ကြုံတွေ့ရတဲ့ experience က စကားပြောတယ်လို့ ခံစားမိတယ်။

## Hackathon မဝင်ခင် စာရေးသူရဲ့အမြင်

ပြိုင်ပွဲတွေ မပြိုင်ဖူးခင်ကတည်းက ကိုယ့် field နဲ့ သက်ဆိုင်တဲ့စာတွေ ဖတ်တယ်၊ လက်တွေ့လည်း လေ့ကျင့်တယ်။ Project လုပ်တဲ့အခါလည်း ကိုယ့် skill တိုးတက်စေမယ့် project တွေကိုပဲ ရွေးလုပ်တယ်။

အဲဒီတုန်းက feature အများကြီးပါတဲ့၊ complex ဖြစ်တဲ့ project အကြီးကြီးတွေမှ ကောင်းတယ်လို့ ထင်ခဲ့တာ။ Static website လေးပါကွာဆိုပြီး အထင်သေးခဲ့ဖူးသလို မလုပ်ချင်ခဲ့ဘူး။

## Hackathon ဝင်ပြိုင်ပြီးနောက်

Hackathon ဝင်ပြိုင်ပြီးနောက် အကြီးမားဆုံး ပြောင်းလဲသွားတဲ့အမြင်ကတော့ **project တစ်ခု ဘယ်လောက်ကြီးပြီး complex ဖြစ်လဲဆိုတာထက် ဘယ်ပြဿနာကို ဖြေရှင်းပေးနိုင်လဲဆိုတာ ပိုအရေးကြီးတယ်** ဆိုတာပါပဲ။

ဘယ်လောက်ပဲ အရမ်းကောင်းတဲ့ project အကြီးကြီး ရေးထားပါစေ၊ ကိုယ့် product က ဘယ်ပြဿနာကိုမှ မဖြေရှင်းပေးနိုင်ရင် အဓိပ္ပာယ် မရှိသလောက်ပဲ။ အဲဒီကနေ real-world product တစ်ခုကို ဘယ်လိုစဉ်းစားရလဲဆိုတာ နားလည်လာတယ်။

တချို့ပြဿနာလေးတွေကို static website တစ်ခုနဲ့တင် ဖြေရှင်းပေးလို့ ရတယ်။ Static လေးပဲဆိုပြီး အထင်သေးလို့ မရဘူး။ တစ်ယောက်ယောက်ရဲ့ ပြဿနာကို ဖြေရှင်းပေးနိုင်တယ်ဆိုကတည်းက အဲဒီ project မှာ value တစ်ခု ရှိနေပြီ။

## အနည်းဆုံး တစ်ခေါက်လောက် စမ်းကြည့်ပါ

ဒီလိုအသိမျိုးကို ပြိုင်ပွဲတွေ ဝင်ပြိုင်ဖူးမှ သိနိုင်တယ်လို့တော့ မပြောချင်ပါဘူး။ ဒါပေမယ့် ကျောင်းတက်ကာစ ကျောင်းသားတွေ၊ ကိုယ့်ဘာသာ လေ့လာနေတဲ့သူတွေအနေနဲ့ အနည်းဆုံး တစ်ခေါက်လောက် hackathon ဝင်ပြိုင်ကြည့်တာက အမြင်တွေ အများကြီး ပွင့်လာစေနိုင်တယ်လို့ စာရေးသူ ယုံကြည်ပါတယ်။
