ကွန်ပျူတာ တက္ကသိုလ်မတက်ရင် ဘာတွေဖြစ်နိုင်လဲ? Code ရေးတတ်ရုံနဲ့ ရပြီလား?

ဒီမေးခွန်းတွေကို အခုချိန်မှာ တက္ကသိုလ်မတက်ဖူးဘဲ programming ကို ကိုယ်တိုင်လေ့လာ‌‌နေ တဲ့သူတစ်ယောက်အနေနဲ့ ကိုယ့်ကိုယ်ကိုယ် ပြန်မေးမိတယ်။

ဆယ်တန်းပြီးတဲ့အခါ ၂၀၂၁ ခုနှစ်လောက်က IT ရယ် ဘာရယ် မသိဘဲ ‌ယောင်လည်လည်နဲ့ ရောက်လာခဲ့တာ။ Data Land Technology မှာ web development foundation ကို online ကနေ တက်ရင်း စမ်းရင်းပြုရင်းနဲ့ စိတ်၀င်စားလာရာကနေ development နဲ့ပတ်သပ်ပြီး နည်းနည်းပါးပါး ရေးတတ်လာတယ်ပေါ့။

## ပထမဆုံး project နဲ့ စတင်ခဲ့တဲ့အချိန်

သင်ထားတဲ့အရာကို အမြဲ applied လုပ်ချင်စိတ်ကရှိတော့ project ခပ်ကြီးကြီးတစ်ခုကို စရေးမယ်ဆိုပြီး  ရွေးလိုက်တာ perfume e-commerce site လေးတစ်ခုပေါ့။ အဲ့တုန်းကတော့ project အကြီးကြီးလို့ ထင်ခဲ့တာပဲ။

ပထမဆုံးအနေနဲ့ code ကိုပဲ စကိုင်တယ်။ Design idea မရှိ။ UI/UX ဆိုတာ ဉီးနှောက်ထဲ ကလော်ရင်တောင်မတွေ့။ Data ရှာဖို့ လိုတယ်ဆိုတာတောင် မသိခဲ့ဘူး။ ER diagram, documentation, flowchart ဆိုတာတွေလည်း ကြားတောင်မကြားဖူးဘဲ စည်းလွတ်ဝါးလွတ် ရေးတယ်ပေါ့။ 

Website အမျိုးမျိုးတွေထဲက reference ယူလို့ရတဲ့ design တွေ့ရင် အဲ့တိုင်း လိုချင်သလိုလေးရေးတယ်။ အဲ့တုန်းက reference ယူလို့ကောင်းတဲ့ website တွေလည်း မသိခဲ့ပါဘူး။ လိုအပ်တဲ့ data တွေကိုလည်း ရေးနေရင်းနဲ့မှ internet ပေါ်ကနေရှာပြီး  သုံးတယ်။  အဲ့တုန်းက data ရှာရတာ အရမ်းစိတ်ညစ်တာ။ database table တွေကိုလည်း ရေးရင်းနဲ့ပဲ ထည့်ဖို့လိုရင် ဆောက်တယ်။ အဓိကက “code ရေးပြီး project တစ်ခုဖြစ်သွားရင် ပြီးပြီ” ဆိုတဲ့ mindset ပဲရှိခဲ့တယ်။ 

## Coding ထက် ပိုနားလည်လာခဲ့တာ

နောက်တော့ Diploma အတန်း တက်ရင်း project တွေလုပ်ရတော့မှ သီအိုရီတွေ သင်ရတယ်။ UML တွေ ဘာညာနဲ့မှ "ဪ ဒါက ဒီလိုတွေရှိပါလား" ဆိုတာ သိရတယ်။ project တစ်ခုလုပ်မယ်ဆို ဘာတွေလုပ်ရတယ် ဆိုတာမျိုး‌ပေါ့။

အဲ့တော့မှ “Code ရေးတတ်တာ” နဲ့ “Software Development ကို နားလည်တာ” က မတူဘူးဆိုတာ နည်းနည်းသဘောပေါက်လာတယ်။ အလုပ်ခေါ်စာတွေမှာ ဘွဲ့တစ်ခုကို ဘာကြောင့် သတ်မှတ်ထားတတ်လဲဆိုတာကိုလည်း နည်းနည်းနားလည်လာတယ်။

ဘွဲ့တစ်ခုနဲ့ ဘာကြောင့် သတ်မှတ်ကြလဲဆိုတော့ ဘွဲ့ကို တန်ဖိုးထားတာမဟုတ်ပါဘူး။ အဲ့ဘွဲရဖို့အတွက်သင်ခဲ့ရတဲ့ ပညာရပ်တွေကို အသိမှတ်ပြုကြတာပါ။ဒါပေမယ့် degree တစ်ခုရှိတာနဲ့ skill ရှိပြီးသားလို့ မဆိုနိုင်သလို၊ degree မရှိတာနဲ့ knowledge မရှိဘူးလို့လည်း မဆိုနိုင်ပါဘူး။

## ရှေ့ဆက်လေ့လာဖို့ လိုအပ်တာတွေ

Skill ရှိရုံနဲ့ career စတင်လို့ရပါတယ်။ တကယ်ဆို အလုပ်လုပ်ရင်း experience ကနေ knowledge အများကြီးရနိုင်ပါတယ်။ ဒါပေမယ့် senior level, architecture, technical leadership, system design လို ပိုကျယ်တဲ့ responsibility တွေကို သွားချင်လာတဲ့အခါ fundamentals နဲ့ theory တွေက ပိုပြီးအရေးကြီးလာတယ်လို့ ကိုယ်တော့ မြင်မိတယ်။

“ဘယ်လိုရေးရမလဲ” ဆိုတာထက် “ဘာကြောင့် ဒီလိုရေးရတာလဲ” ဆိုတာကို ပိုမေးဖြစ်လာတယ်‌‌ပေါ့။

Code က စတင်ဖို့အတွက် အရေးကြီးတယ်။ ဒါပေမယ့် system တစ်ခုကို နားလည်ဖို့၊ problem ကို ဖြေရှင်းဖို့နဲ့ ကြီးမားတဲ့ responsibility တွေကို ကိုင်တွယ်ဖို့အတွက်တော့ coding skill ထက်ပိုတဲ့ knowledge တွေ လိုအပ်လာတယ်‌ပေါ့။

ဒါကြောင့် ကိုယ့်အမြင်မှာတော့ University မတက်ခဲ့တာဟာ လမ်းပိတ်သွားတာမဟုတ်ဘဲ ကိုယ်တိုင်ဖြည့်ဆည်းရမယ့် knowledge တွေတော့ ပိုများလာတယ်လို့ မြင်မိတယ်။

ဒါကတော့ အခု diploma အတန်းပြီးခါစ လုပ်ငန်းခွင်မ၀င်ရသေးတဲ့ junior level  ပေါက်စလေးရဲ့ အမြင်သာ ဖြစ်ပါတယ်။ နောက် အသက်အရွယ်တစ်ခု ရလာတဲ့အခါ ဘယ်လိုတွေကွာခြားသွားမလဲတော့ မသိနိုင်သေးဘူးပေါ့။
